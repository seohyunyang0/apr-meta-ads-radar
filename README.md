# APR 메타 광고 레이더

메디큐브·에이프릴스킨 공식 페이지 8곳이 Meta에서 집행 중인 광고를 국가·운영일수·노출 순위로 보는 대시보드입니다.

- 데이터: Meta 광고 라이브러리 공개 페이지 (2026-11-21 수집, 활성 광고만)
- CPC·ROAS는 공개되지 않아, 운영일수 백분위와 페이지 내 노출 순위 백분위로 만든 효율 지수(0–100)를 대리지표로 씁니다.
- 폰트: Paperlogy (SIL Open Font License), 한글·라틴만 서브셋

## 구성
1. 나라별로 돌아가는 광고
2. 운영일수와 콘텐츠 효율 (나라별 형식·랜딩·주제·훅 효율, 효율 지수 상위 소재)
3. 나라별 인사이트와 제안 (미국·영국·프랑스)
4. 전체 광고 통합 리스트 (광고 라이브러리 미리보기·랜딩 링크)
